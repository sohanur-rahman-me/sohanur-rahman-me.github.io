# Sohanur Rahman — Professional Portfolio

Personal portfolio for **Sohanur Rahman**, final-year Mechanical Engineering student at Rajshahi University of Engineering & Technology (RUET), Bangladesh.

## Portfolio focus
- Sustainable materials and natural-fibre composite research
- Undergraduate thesis on bamboo–jute epoxy hybrid composites modified with nanoclay
- Conference publication and engineering projects
- Industrial attachment and power-plant exposure
- CAD/CAE, experimental work, and manufacturing / production interests
- Professional development and contact links

## Website
The portfolio is built as a responsive, static website in `index.html`, using HTML and CSS with no build tools or JavaScript frameworks required.

## Publishing with GitHub Pages
1. Open the repository **Settings**.
2. Select **Pages** from the sidebar.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch `main` and folder `/ (root)`, then save.
5. The site should publish at: https://sohanur-rahman-me.github.io/

## Before sharing widely
- Verify the profile photo, contact email, LinkedIn URL, CGPA, graduation date, and all project details.
- Add downloadable PDF versions of the academic and professional CVs, certificates, and publication only after reviewing the files for personal contact details and permission to share.
- Add ORCID / Google Scholar links once those profiles are ready.
- Update thesis results only after the experiments and analysis are complete.
